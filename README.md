# 原價屋簡單爬蟲

目前僅實現爬取傳統內接硬碟資料，並轉成簡單篩選網頁，包含每T價格比較。


## 使用方法 (擇一)

1. 運行 internal_hdd.py
```shell script
python internal_hdd.py
```
2. 直接雙擊 Run.bat (Windows)

## Path

- 結果網頁
    - res/html/internal-hdd-{yyyymmdd}.html
